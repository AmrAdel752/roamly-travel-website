# Roamly

Roamly is a modern static travel discovery experience built as a frontend portfolio project. It presents curated destination content, lightweight planning interactions, and responsive UI patterns for a polished travel website concept.

This is not a real travel company. It is a frontend project designed to demonstrate UI modernization, responsive layout, JavaScript enhancement, and accessible interaction design.

## Features

- Responsive travel discovery interface
- Destination discovery cards with category filtering
- Trip planner demo with destination, date, and traveler controls
- Favorites saved with `localStorage`
- Responsive mobile navigation
- FAQ accordion
- Contact and newsletter form validation
- Accessibility features including semantic sections, skip link, ARIA states, keyboard-aware navigation, and reduced-motion support
- Smooth scrolling, animated UI states, and responsive visual effects
- Fully responsive design for desktop, tablet, and mobile screens

## Running Locally

No build system is required. Open the project with a static server, such as the Live Server extension in VS Code.

You can also run a basic static HTTP server from the project root:

```bash
python -m http.server
```

Then open the local server address shown in the terminal.
